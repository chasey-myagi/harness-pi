# 扫描器标本语料

`src/__tests__/import-graph.test.ts` 的扫描器有十来条分支，而 runtime 图今天只有 4 个纯类型
文件、零命中——`expect(hits).toEqual([])` 对那些分支恒真，写错了也永远发现不了。

这个目录是**给扫描器看的标本**，不被任何 tsconfig 编译、不被 vitest 收集。测试断言
`scan()` 在这里的命中集合**精确等于**预期集合（不是「非空」），从而给每条分支一个正向对照；
`negative-control.ts` 给出必须**不**被误报的形态。

新增扫描分支时，请同时往这里加标本——否则那条分支和它守的不变量一样没有证据。
